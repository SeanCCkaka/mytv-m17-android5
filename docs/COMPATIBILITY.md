# 设备与可用版本

## 已验证

| 项目 | 结果 |
| --- | --- |
| 设备 | 天猫魔盒 M17 |
| 系统 | Android 5.1.1 / API 22（YunOS 固件） |
| 架构 | ARMv7 / `armeabi-v7a` |
| 可用版本 | `v0.1.2-m17-test`，`versionCode = 3` |
| 使用的播放路径 | 关闭“兼容播放（VLC 软件解码）”，使用 Media3 自动/硬件解码 |
| 实机视频解码器 | `OMX.amlogic.avc.decoder.awesome` |
| 频道 | 39 个，核验日期 2026-10-26 |
| 遥控器 | 左键打开列表、上下选择、确定切台、返回关闭，使用者实测通过 |

## 配置与验证边界

初次安装的软件解码开关仍为早期测试默认值，使用本次已验证的播放路径时需要在设置中将其关闭。软件解码可以通过低分辨率离线自检，但对高分辨率直播可能卡顿。

15 个卫视的正常播放由使用者在电视上确认。另对 16 个央视及 8 个浙江频道检查了首帧和短时连续画面输出；这不能替代逐台人工音画同步测试或长期稳定性测试。

山东卫视曾出现声音领先画面，重新打开频道后使用者确认恢复同步，根本原因尚未确定。

当前表删除了无法在该网络播放或未纳入已验证集合的项目，并合并重复频道。CCTV-5+ 和 CCTV-16 的原地址需要 IPv6，本次家庭网络无可用 IPv6，因此未保留。

其他机型、Android 5.0、Android 8 及 ARM64 均未实测；应用只包含 ARMv7 原生库。这里的“可用”只指上述设备、版本和验证范围。
