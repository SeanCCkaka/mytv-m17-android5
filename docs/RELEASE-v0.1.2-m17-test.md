# v0.1.2-m17-test · 天猫魔盒 M17 实测可用

适用已验证设备：**天猫魔盒 M17 / Android 5.1.1 / ARMv7**。

首次安装后，在设置中**关闭“兼容播放（VLC 软件解码）”**，使用已在魔盒上验证的 Media3 自动/硬件解码路径。

本版本包含：

- 遥控器左键打开频道列表，上下选择、确定切台、返回关闭。
- 39 个去重频道：央视 16 个、卫视 15 个、浙江频道 8 个。
- YunOS 系统旧版 Guava 隔离修复。
- 12 秒离线画面与声音自检、有限自动换源。

构建与 35 项已有单元测试通过，lint 0 错误。已在魔盒上验证频道菜单和切台操作，使用者确认遥控器检查正常。

频道核验日期为 2026-10-26，公开地址会随时间变化。其他机型未实测；山东卫视曾出现短暂音画不同步，重开后恢复，未确定根本原因。

源码版本：`0.1.2-m17-test`，Android `versionCode = 3`。详细设备范围和构建方法见仓库 README。
